# No Rebranding

Cuando trabajes sobre la web, landing pages o interfaces en este repositorio:

- No hagas rebranding.
- No cambies la identidad visual existente.
- No sustituyas la paleta de color actual por una nueva.
- No cambies tipografias, estilos base, tono visual ni lenguaje de marca salvo que el usuario lo pida de forma explicita.
- No redisenes la UI por iniciativa propia.

Esto implica que, por defecto:

- Debes conservar colores, jerarquia visual, espaciados generales, componentes visibles y estructura de marca existentes.
- Solo puedes hacer ajustes visuales minimos cuando sean necesarios para corregir bugs, mejorar accesibilidad o adaptar contenido sin alterar la identidad de la web.
- Si una peticion funcional exige tocar estilos, debes mantener el look and feel actual y limitar el cambio al minimo necesario.

Si el usuario solicita una mejora visual ambigua, interpreta la instruccion de forma conservadora:

- mejora sin rebrand,
- optimiza sin cambiar la marca,
- corrige sin introducir una nueva direccion visual.

Si una tarea realmente requiere cambiar branding, paleta, estilo global o direccion visual, pide confirmacion explicita antes de hacerlo.
